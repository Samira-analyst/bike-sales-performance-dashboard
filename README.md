# Bike Sales & Customer Demographics Dashboard

## Overview
This repository contains an interactive Excel dashboard designed to analyze customer data and identify key factors influencing bike purchasing behavior. The project transforms raw demographic data into actionable insights for targeted marketing and sales strategies.

## Tools & Techniques Used
* **Microsoft Excel** (Data Cleaning & Analysis)
* **Pivot Tables & Pivot Charts** (Dynamic data aggregation)
* **Advanced Formulas** (Nested IFs, Age Bracketing, and Data Standardization)
* **Interactive Slicers** (For dynamic filtering by Region, Education, and Marital Status)
* **Data Visualization** (Professional charting aligned with corporate standards)

## Key Insights & Features
* **Income Analysis:** Visualized the average income of buyers vs. non-buyers, segmented by gender.
* **Commute Distance Impact:** Analyzed how the distance between home and work affects the willingness to purchase a bike.
* **Age Demographics:** Grouped customer ages into custom brackets (Adolt, Middle-Age, Old) using Excel logic to discover the primary target market.
* **Geographical Insights:** Regional analysis of sales performance across Europe, Pacific, and North America.

## Project Structure
* `Excel Project Dataset.xlsx`: The main workbook containing the raw data, processed working sheets, pivot tables, and the final dashboard.
* `bike-sale-dashboard.png`: A high-quality screenshot of the interactive Excel dashboard.
